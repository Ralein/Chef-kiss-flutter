# Chef-kiss-flutter

Artisanal illustrated recipe keepsake & kitchen cook companion built with Flutter & Dart.

## Features
- **Artisanal Keepsake Book Spread**: Double-page layout on desktop and swipeable card stack on mobile.
- **Drift SQLite Storage**: Local offline recipe storage with full versioning and provenance metadata.
- **Interactive Scrapbook Canvas**: In-line editing, free-floating stickers, washi tapes, and live Polaroid tilt.
- **100+ Culinary Icons**: Rich culinary iconography across 7 categories with custom ink swatches.
- **Kitchen Cook Mode**: Full-screen distance-readable cooking companion with step timers, ambient dark mode, and victory fanfare.
