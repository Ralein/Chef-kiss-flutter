Source artwork for the brand, kept out of the app bundle.

  `assets/illustrations/splash_medallion.png` were made from it.
- `chef_kiss_badge.svg`: the logo as a ringed badge.
- `app_logo_chef_kiss.jpg`: the original logo artwork.

The app itself uses `assets/illustrations/chef_kiss_logo.svg` (navigation rail
badge) and `assets/illustrations/splash_medallion.png` (launch screens).
